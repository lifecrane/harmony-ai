# cheatsheet

1. `ollama list` — models on disk
2. `ollama run lfm2-1.2b-rag:latest` — fast chat in terminal
3. `aichat -e "hi"` — test the aichat backend
4. `summarize cheatsheet` — panel summarizes this file
5. `switch to .role plan` — committed ordered plan
6. `switch to .role exec` — write code
7. `switch to .role qc` — review only
8. `Shift+B` — toggle file tree
9. `./run_panel.sh` — start the panel (:8080)
10. `curl localhost:8080` — is the panel up?
